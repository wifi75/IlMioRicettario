# Il Mio Ricettario

Sistema avanzato per la gestione e il calcolo di ricette di panificazione.

## Funzionalità attuali

* Login amministratore
* Gestione ricette
* Gestione ingredienti
* Calcolo automatico:

  * Farine totali
  * Liquidi totali
  * Idratazione
* Ingredienti classificabili come:

  * Farina
  * Liquido
* Database SQLite
* Interfaccia responsive Bootstrap 5
