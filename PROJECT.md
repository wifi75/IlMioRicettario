# PROJECT

## Nome

Il Mio Ricettario

## Versione

V1

## Descrizione

Il Mio Ricettario è una piattaforma web sviluppata in Flask per la gestione di ricette dinamiche.

A differenza di un semplice ricettario, ogni ricetta può attivare moduli e motori di calcolo configurabili dal backend.

Il sistema è progettato principalmente per:

* Panificazione
* Pizza
* Focacce
* Panini
* Lievitati dolci
* Impasti professionali
