Ripristina Backup

Carica un file .json o .zip precedentemente esportato per ripristinare ricette, configurazione o entrambi.

Formati accettati: .json (ricette o configurazione) oppure .zip (backup completo).
Note sul sistema di backup
Portabilità
I file JSON esportati sono compatibili tra installazioni diverse dello stesso progetto. Utili per migrare da un server all'altro.
Immagini
Le immagini delle ricette sono incluse solo nel backup completo ZIP. I backup JSON contengono solo i metadati.
Frequenza consigliata
Esegui un backup completo prima di ogni aggiornamento dell'applicazione e almeno una volta a settimana in produzione.
